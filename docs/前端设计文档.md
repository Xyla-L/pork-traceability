# 猪肉产品质量安全溯源系统 — 前端设计文档

---

## 一、项目概览

### 1.1 前端项目组成

```
猪肉溯源系统 — 前端
│
├── trace-web-admin/          # Web管理端（Vue3 + Element Plus）
│   └── 面向角色：养殖场 / 屠宰场 / 分割配送 / 零售商 / 监管 / 管理员
│
└── trace-mini-app/           # 消费者小程序（Uni-app + uView）
    └── 面向角色：消费者（扫码溯源、安心购、一键验真、举报）
```

### 1.2 技术选型

| 类别 | Web管理端 | 消费者小程序 |
|------|----------|-------------|
| 框架 | Vue 3.4 + Composition API | Uni-app 3.x (基于Vue3) |
| 构建工具 | Vite 5.x | Uni-app CLI / HBuilderX |
| UI组件库 | Element Plus 2.x | uView Plus 3.x |
| 状态管理 | Pinia 2.x | Pinia 2.x |
| 路由 | Vue Router 4.x | uni-app 自带路由 (pages.json) |
| HTTP客户端 | Axios 1.x | uni.request + 封装拦截器 |
| 图表 | ECharts 5.x | uCharts (小程序轻量版) |
| 二维码 | qrcode.js (生成) / html5-qrcode (扫码) | uni.scanCode (原生扫码) |
| 签名板 | vue-signature-pad | — |
| 地图 | — | uni.openLocation (原生) |
| 文件上传 | Element Plus Upload + 分片 | uni.uploadFile |
| 样式预处理 | SCSS | SCSS |
| 代码规范 | ESLint + Prettier | ESLint + Prettier |
| 兼容目标 | Chrome/Edge/Firefox 近2个主版本 | 微信小程序基础库 2.25+ |

### 2.6 API 层设计 (Axios 封装)

```javascript
// src/api/request.js — 统一请求封装
import axios from 'axios'
import { ElMessage } from 'element-plus'
import router from '@/router'
import { useAuthStore } from '@/stores/auth'

const request = axios.create({
  baseURL: import.meta.env.VITE_API_BASE || '/api/v1',
  timeout: 30000
})

// 请求拦截器
request.interceptors.request.use(config => {
  const authStore = useAuthStore()
  if (authStore.token) {
    config.headers.Authorization = `Bearer ${authStore.token}`
  }
  return config
})

// 响应拦截器
request.interceptors.response.use(
  response => {
    const { code, message, data } = response.data
    if (code === 200) return data
    // 上链中的状态码不是错误
    if (code === 10001) {
      ElMessage.warning(message || '数据上链中，请稍后查看')
      return data
    }
    ElMessage.error(message || '请求失败')
    return Promise.reject(new Error(message))
  },
  error => {
    if (error.response?.status === 401) {
      const authStore = useAuthStore()
      authStore.logout()
      router.push('/login')
    }
    ElMessage.error(error.message || '网络错误')
    return Promise.reject(error)
  }
)

export default request
```

### 3.4 小程序 API 层设计

```javascript
// src/api/index.js — Uni-app 请求封装
const BASE_URL = 'https://api.example.com/api/v1'

const request = (url, options = {}) => {
  return new Promise((resolve, reject) => {
    uni.request({
      url: BASE_URL + url,
      method: options.method || 'GET',
      data: options.data,
      header: {
        'Content-Type': 'application/json',
        ...options.header
      },
      success: (res) => {
        const { code, message, data } = res.data
        if (code === 200) {
          resolve(data)
        } else {
          uni.showToast({ title: message || '请求失败', icon: 'none' })
          reject(new Error(message))
        }
      },
      fail: (err) => {
        uni.showToast({ title: '网络异常，请稍后重试', icon: 'none' })
        reject(err)
      }
    })
  })
}

// 扫码溯源
export const scanProduct = (qrCode) => request(`/consumer/scan/${qrCode}`)

// 安心购
export const getSafeBuy = (qrCode) => request(`/consumer/safe-buy/${qrCode}`)

// 一键验真
export const verifyProduct = (qrCode) => request('/consumer/verify', {
  method: 'POST',
  data: { qrCode }
})

// 提交举报（含图片上传）
export const submitComplaint = async (formData) => {
  // 先上传图片
  const fileIds = []
  for (const photo of formData.photos) {
    const uploadRes = await uni.uploadFile({
      url: BASE_URL + '/file/upload',
      filePath: photo,
      name: 'file'
    })
    const { fileId } = JSON.parse(uploadRes.data).data
    fileIds.push(fileId)
  }
  // 再提交举报
  return request('/trace/complaints', {
    method: 'POST',
    data: { ...formData, fileIds }
  })
}
```

### 5.2 区块链上链状态轮询

```javascript
// composables/useBlockchainVerify.ts
// 当API返回 code=10001（上链中）时，启动轮询
export function useBlockchainVerify(bizType, bizId) {
  const status = ref('pending') // 'pending' | 'confirmed' | 'failed'
  const txHash = ref('')
  let timer = null

  const startPolling = () => {
    status.value = 'pending'
    let retryCount = 0
    timer = setInterval(async () => {
      const res = await blockchainApi.getRecord(bizType, bizId)
      if (res.status === 1) {
        status.value = 'confirmed'
        txHash.value = res.txHash
        clearInterval(timer)
      } else if (res.status === 2 || ++retryCount > 30) {
        status.value = 'failed'
        clearInterval(timer)
      }
    }, 2000) // 每2秒轮询一次，最多30次（1分钟）
  }

  const stopPolling = () => { clearInterval(timer) }

  onUnmounted(stopPolling)

  return { status, txHash, startPolling, stopPolling }
}
```

### 5.3 文件上传 + SHA-256 回显

```javascript
// composables/useFileUpload.ts
export function useFileUpload() {
  const fileInfo = reactive({
    fileId: '',
    sha256: '',
    url: '',
    uploading: false
  })

  const upload = async (file) => {
    fileInfo.uploading = true
    const formData = new FormData()
    formData.append('file', file)
    const res = await fileApi.upload(formData)
    // 后端返回: { fileId: "uuid", sha256: "abc123...", url: "/file/uuid" }
    fileInfo.fileId = res.fileId
    fileInfo.sha256 = res.sha256
    fileInfo.url = res.url
    fileInfo.uploading = false
  }

  return { fileInfo, upload }
}
```
