# 自然语言操作 · 接口文档

> 面向：前端。五个接口，两个必接、三个可选。
> 后端模块：`ai-service`。鉴权、响应外壳与现有接口一致。

---

## 一、通用约定

**网关前缀**：`/api/v1`

**鉴权**：带现有 JWT（`Authorization: Bearer <token>`），网关解析出用户身份。
前端不需要也不应该自己塞 `X-User-Id`。

**响应外壳**：所有接口统一 `Result<T>`。

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { },
  "traceId": "2db0825d12a94aa29e0ffc5b1480e144",
  "timestamp": 1795072711949
}
```

**协议**：普通 JSON（`Content-Type: application/json`），不是 SSE。流式只用于「问答」模式，与本文无关。

### 错误码

| code | 场景 | 前端处理 |
|---|---|---|
| 200 | 请求正常处理完。**业务失败也是 200**，看 `data.phase` | 按 `phase` 渲染 |
| 400 | 缺必填参数 | 前端 bug |
| 401 | 未登录 / token 失效 | 跳登录 |
| 403 | 调 `/ai/admin/**` 但角色不足 | 提示无权限 |
| 503 | 后端把该功能关掉了 | 提示「功能暂未开放」|

> 不要用 `response.ok` 或 `code === 200` 判断业务成败，一律看 `data.phase`。

### 接口清单

| 方法 | 路径 | 必接 |
|---|---|---|
| POST | `/ai/action/chat` | 是 |
| POST | `/ai/action/confirm` | 是 |
| GET | `/ai/graph/search` | 否（调试用） |
| GET | `/ai/graph/stats` | 否（排障用） |
| POST | `/ai/admin/graph/rebuild` | 否（管理端） |

## 二、POST `/ai/action/chat`

把一句话翻译成接口调用。多轮补参数走这个接口。

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `text` | string | 是 | 用户原话，上限 500 字 |
| `conversationId` | string | 否 | 上一轮返回值。传 `""` 或 `null` 都表示新会话 |
| `reset` | boolean | 否 | `true` 丢弃上下文重开 |

> 字段名是 **`text`**，不是 `message`。写错会被静默忽略，表现为「请输入你想做的事」。

```json
{
  "text": "查看产地检疫证明",
  "conversationId": ""
}
```

### 响应 `data`

| 字段 | 类型 | 说明 |
|---|---|---|
| `phase` | string | `UNSUPPORTED` / `NEED_SLOT` / `READY` / `EXECUTED` / `FAILED`，见下节 |
| `conversationId` | string | 后续轮次带上这个值 |
| `operation` | object \| null | 命中的接口，`UNSUPPORTED` 时为 `null` |
| `operation.id` | string | 接口标识，形如 `op:breeding-service:GET:/pigs/{pigId}/quarantine-cert` |
| `operation.summary` | string | 中文摘要，如「查看产地检疫证明」 |
| `operation.method` | string | HTTP 方法 |
| `operation.path` | string | 服务内路径 |
| `operation.gatewayPath` | string | 带网关前缀的完整路径（展示用） |
| `operation.module` | string | 模块名 |
| `operation.service` | string | 服务名 |
| `slots` | object | 已收集的参数。**执行完成后为空对象** |
| `missing` | array | 仍缺的必填参数，`[{name, type, hint}]` |
| `question` | string | 要说给用户的话（追问或结论） |
| `answer` | string | 同上，内容与 `question` 一致，展示其一即可 |
| `execution` | object \| null | 执行结果，未执行时为 `null` |
| `execution.success` | boolean | 业务是否成功 |
| `execution.status` | int | 下游 HTTP 码，`-1` 表示请求未发出 |
| `execution.elapsedMs` | long | 耗时（ms） |
| `execution.data` | string \| null | 下游原始响应，**JSON 字符串，需自行 parse** |
| `execution.error` | string \| null | 失败原因（已脱敏，截断 200 字） |
| `candidates` | array | 候选接口 `[{id, summary, method, score}]` |

### `phase` 五种状态

| phase | 含义 | 前端动作 |
|---|---|---|
| `UNSUPPORTED` | 没匹配到功能 | 展示 `question` |
| `NEED_SLOT` | 接口命中但缺参数 | 展示 `missing`，等用户补充后再次调本接口（带 `conversationId`） |
| `READY` | 写操作，参数齐，待确认 | 展示确认按钮，点击调 `/ai/action/confirm` |
| `EXECUTED` | 执行成功 | 展示 `execution.data` |
| `FAILED` | 执行失败，或未执行（会话过期 / 文本超长 / 功能关闭） | 有 `execution` 展示错误面板，无则展示 `question` |

### 示例 1：缺参数

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "phase": "NEED_SLOT",
    "conversationId": "d1f38717-7bd7-4b2f-b1e0-65a704dc2422",
    "operation": {
      "id": "op:breeding-service:GET:/pigs/{pigId}/quarantine-cert",
      "summary": "查看产地检疫证明",
      "method": "GET",
      "path": "/pigs/{pigId}/quarantine-cert",
      "gatewayPath": "/api/v1/breeding/pigs/{pigId}/quarantine-cert",
      "module": "产地检疫证明管理",
      "service": "breeding-service"
    },
    "slots": {},
    "missing": [{ "name": "pigId", "type": "Long", "hint": "数字" }],
    "question": "要查看产地检疫证明，还需要补充：pigId（数字）。",
    "answer": "要查看产地检疫证明，还需要补充：pigId（数字）。",
    "execution": null,
    "candidates": [
      { "id": "op:breeding-service:GET:/pigs/{pigId}/quarantine-cert", "summary": "查看产地检疫证明", "method": "GET", "score": 0.944 },
      { "id": "op:breeding-service:GET:/records/certs", "summary": "产地检疫按批次分组", "method": "GET", "score": 0.852 }
    ]
  },
  "traceId": "3db5601d90d74a7bae6d71ad3f253d3d",
  "timestamp": 1795072712200
}
```

### 示例 2：执行成功

```json
{
  "code": 200,
  "data": {
    "phase": "EXECUTED",
    "conversationId": "d1f38717-7bd7-4b2f-b1e0-65a704dc2422",
    "operation": {
      "id": "op:breeding-service:GET:/pigs/{pigId}/quarantine-cert",
      "summary": "查看产地检疫证明",
      "method": "GET",
      "path": "/pigs/{pigId}/quarantine-cert",
      "gatewayPath": "/api/v1/breeding/pigs/{pigId}/quarantine-cert",
      "module": "产地检疫证明管理",
      "service": "breeding-service"
    },
    "slots": {},
    "missing": [],
    "question": "已执行「查看产地检疫证明」。共 1 条。",
    "answer": "已执行「查看产地检疫证明」。共 1 条。",
    "execution": {
      "success": true,
      "status": 200,
      "elapsedMs": 87,
      "data": "{\n  \"code\": 200,\n  \"data\": { \"pigId\": 1, \"certNo\": \"JY20261101001\" }\n}",
      "error": null
    },
    "candidates": []
  }
}
```

> `slots` 为空是正常的：执行成功后后端会清空参数，避免下一次误用旧值。

```json
{

  "operation": { "id": "op:breeding-service:POST:/farms", "summary": "创建养殖场", "method": "POST" },
  "slots": { "farmName": "示范猪场" },
  "missing": [],
  "question": "即将执行「创建养殖场」（POST /farms），确认继续吗？"
}
```

## 三、POST `/ai/action/confirm`

用户点击「确认执行」时调用。

### 请求体

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `conversationId` | string | 是 | 上一步 `READY` 返回的值 |

```json
{ "conversationId": "d1f38717-7bd7-4b2f-b1e0-65a704dc2422" }
```

**只传会话 id，不回传参数。** 参数保留在服务端会话中，前端无法绕过参数校验。

### 响应

与 `/ai/action/chat` 结构完全一致。`phase` 一般为 `EXECUTED` 或 `FAILED`，
极少数情况为 `NEED_SLOT`（确认期间参数被清空，退回补参）。

### 会话失效

会话默认 10 分钟过期；同一会话确认执行一次后不能再次确认。
失效时返回 `phase: "FAILED"`，`question` / `answer` 可能是：

- `会话已过期，请重新描述一次要做什么。`
- `当前没有等待确认的操作。`
- `选中的接口已经不在图谱里了，请重新发起。`

点击确认后请置 loading 并禁用按钮，避免重复提交。

## 四、GET `/ai/graph/search`（可选）

只检索、不执行。用于排查「为什么没找到 / 为什么选了这个」。

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `q` | string | 是 | 自然语言，需 `encodeURIComponent` |
| `topK` | int | 否 | 默认 8，服务端限制 1~20 |

### 响应 `data`

| 字段 | 说明 |
|---|---|
| `query` | 原始查询 |
| `count` | 返回条数 |
| `items[].id` / `.method` / `.path` / `.gatewayPath` / `.summary` | 接口信息 |
| `items[].score` | 相关度 0~1 |
| `items[].hits` | 命中的词 |
| `items[].executable` | 是否允许通过对话执行 |
| `items[].denyReason` | 不允许时的原因。**允许时该字段不存在** |

```json
{
  "code": 200,
  "data": {
    "query": "查看产地检疫证明",
    "count": 2,
    "items": [
      {
        "id": "op:breeding-service:GET:/pigs/{pigId}/quarantine-cert",
        "method": "GET",
        "path": "/pigs/{pigId}/quarantine-cert",
        "gatewayPath": "/api/v1/breeding/pigs/{pigId}/quarantine-cert",
        "summary": "查看产地检疫证明",
        "score": 0.944,
        "hits": ["查看", "看产", "产地", "地检", "检疫", "疫证", "证明", "quarantine", "cert"],
        "executable": true
      },
      {
        "id": "op:breeding-service:POST:/pigs/{pigId}/quarantine-cert",
        "method": "POST",
        "path": "/pigs/{pigId}/quarantine-cert",
        "summary": "上传产地检疫证明",
        "score": 0.855,
        "executable": false,
        "denyReason": "「上传产地检疫证明」会修改数据，需要管理员显式开启后才能通过对话执行。"
      }
    ]
  }
}
```

## 五、GET `/ai/graph/stats`（可选）

用于排障：确认图谱是否加载成功。

```json
{
  "code": 200,
  "data": {
    "enabled": true,
    "source": "seed",
    "builtAt": "2026-11-19T07:18:25.286793600Z",
    "moduleCount": 39,
    "operationCount": 218,
    "serviceCount": 10,
    "internalCount": 53,
    "readOnlyCount": 112,
    "services": {
      "breeding-service": 44,
      "distribution-service": 64,
      "auth-service": 22,
      "sales-service": 17,
      "slaughter-service": 18,
      "trace-service": 18,
      "blockchain-service": 11,
      "ingest-service": 9,
      "file-service": 5,
      "ai-service": 10
    }
  }
}
```

`source` 为 `seed`（静态扫描）或 `openapi`（运行时重建）。`operationCount` 为 0 说明图谱未加载。

## 六、POST `/ai/admin/graph/rebuild`（管理端）

从各服务的 `/v3/api-docs` 重建图谱，覆盖内存中的数据。

- 需要 `X-User-Role` 为 `SUPERVISOR` 或 `ADMIN`
- 无请求体
- 部分成功策略：个别服务连不上不影响其它服务，失败原因在 `services[].error`

```json
{
  "code": 200,
  "data": {
    "success": true,
    "message": "重建完成：8/8 个服务成功",
    "operationCount": 218,
    "moduleCount": 39,
    "services": [
      { "service": "breeding-service", "ok": true, "operationCount": 44, "error": null },
      { "service": "sales-service", "ok": false, "operationCount": 0, "error": "连接超时" }
    ]
  }
}
```

## 七、对接注意事项

1. **请求字段是 `text`**，不是 `message`。
2. **`conversationId` 每轮更新**，取响应里的 `data.conversationId`，不要自己生成。
3. **`execution.data` 是字符串**，展示前 `JSON.parse`，解析失败按纯文本显示。
4. **`slots` 执行完为空**，属正常现象。
5. **`candidates` 可能为 0 条**，折叠区先判空。
6. **`denyReason` 可能不存在**，判空取值。
7. **`question` / `answer` 内容相同**，只渲染一个。
8. **输入框建议 `maxlength=500`**，超长会返回 `FAILED`。
9. **降级提示不要过滤**：连不上大模型时 `question` 前会带一段
   「（当前连不上大模型，这是按关键词匹配选出来的接口…）」，属正常提示。
