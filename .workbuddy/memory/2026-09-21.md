## 「屠宰管理页面没数据」排查：两个真 bug 修复

**排查路径**：DB 数据齐全（entry 27/inspection 24/stamp 22/racto 24）→ API 网关/nginx 两链路全通 → nginx 访问日志发现用户 20:03 加载主页后无任何 API 请求 → Edge(playwright-core + msedge.exe headless) 实测发现**管理端整站白屏**。

**Bug 1（根因）：`backend/nginx.conf` 缺 `include /etc/nginx/mime.types`**。自定义 nginx.conf 没引入 MIME 映射，`.js` 静态资源按默认 `text/plain` 下发，浏览器严格 MIME 校验拒绝执行 module script → `#app` 空、整站白屏、所有页面"没数据"。之前只反代 API 不挂静态文件所以没暴露。修复：http 块加 `include /etc/nginx/mime.types; default_type application/octet-stream;` + `docker restart nginx`。

**Bug 2：`EntryTable.vue` / `RactoTable.vue` 漏 import `sourceLabel/sourceTag`**（上次加"数据来源"列时，其他表都从 `@/api/modules/ingest` import 了，唯独这两个文件漏）→ 运行时 `TypeError: sourceTag is not a function`，数据来源列渲染报错。补上 import 即可。
